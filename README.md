# VoxiFy-Voice-to-Text-Converter
🎙️ Voxify is a simple Speech-to-Text web app built using Flask, Python &amp; React. Upload audio files and instantly convert speech into accurate text transcription. ⚡ Supports fast processing, clean UI, and real-time conversion using SpeechRecognition library. 🚀 Perfect for learning AI &amp; audio processing.
